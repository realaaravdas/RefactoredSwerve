# Constants

## `frc2025::Constants`

Central configuration file located in `src/main/include/frc2025/Constants.h`.

### Drive Constants
*   `kDriveMaxSpeed`: Maximum physical speed of the robot.
*   `kDriveMaxAngularRate`: Maximum turning speed.

### Auto Constants
*   `kMaxSpeed`: Max speed during auto.
*   `kMaxAcceleration`: Max acceleration during auto.
*   `PID Constants`: Tuning values for PathPlanner path following.

### Input Constants
*   `kDriveGamepadPort`: USB port for the driver controller.
*   `kSteerJoystickDeadband`: Deadband for joystick inputs.
